Introducción

Los métodos de búsqueda son algoritmos que permiten localizar información dentro de una estructura de datos, como arreglos, listas o tablas. Su objetivo principal es encontrar un elemento determinado de la manera más rápida y eficiente posible.

Existen diferentes métodos de búsqueda y cada uno utiliza procedimientos específicos para localizar los datos. En esta unidad se estudian tres métodos importantes: búsqueda secuencial, búsqueda binaria y búsqueda por funciones de Hash.

Tema 6.1

Búsqueda Secuencial

La búsqueda secuencial, también conocida como búsqueda lineal, es un método que consiste en revisar los elementos de una colección uno por uno, comenzando desde el primero, hasta encontrar el dato que se está buscando o llegar al final de la estructura.

¿Cómo funciona?

  • Se comienza desde el primer elemento del arreglo.
  • Se compara el elemento actual con el valor buscado.
  • Si coinciden, se devuelve la posición del elemento.
  • Si no coinciden, se continúa con el siguiente elemento.
  • El proceso termina cuando se encuentra el dato o se revisan todos los elementos.

Ejemplo práctico

Tenemos el siguiente arreglo y queremos encontrar el número 25:

Arreglo: 10, 15, 20, 25, 30, 35

El algoritmo compara primero 10, después 15, luego 20 y finalmente 25. Al encontrarlo, devuelve su posición.

Resultado: Elemento encontrado en la posición 3 (índice desde 0).

Características

  • No necesita que los datos estén ordenados.
  • Es fácil de comprender e implementar.
  • Funciona con arreglos y listas enlazadas.
  • Revisa los elementos de manera consecutiva.

Ventajas

  • Implementación sencilla.
  • No necesita memoria adicional significativa.
  • Puede trabajar con datos desordenados.

Desventajas

  • Puede ser lento cuando existen muchos elementos.
  • En el peor caso debe revisar toda la colección.

Complejidad

Mejor caso: O(1)

Caso promedio: O(n)

Peor caso: O(n)

Espacial: O(1)

Pseudocódigo

FUNCIÓN busquedaSecuencial(arreglo, dato) PARA i = 0 HASTA longitud(arreglo)-1 SI arreglo[i] == dato ENTONCES RETORNAR i FIN SI FIN PARA RETORNAR -1 FIN FUNCIÓN
Tema 6.2

Búsqueda Binaria

La búsqueda binaria, también llamada búsqueda dicotómica, es un algoritmo que permite localizar un elemento dividiendo repetidamente el conjunto de datos en dos partes. Para funcionar correctamente, los elementos deben estar previamente ordenados.

¿Cómo funciona?

  • Se establece un límite inferior y uno superior.
  • Se calcula la posición del elemento central.
  • Se compara el valor central con el dato buscado.
  • Si el dato es menor, se continúa en la mitad izquierda.
  • Si es mayor, se continúa en la mitad derecha.
  • El procedimiento se repite hasta encontrar el elemento o determinar que no existe.

Ejemplo práctico

Tenemos un arreglo ordenado y queremos encontrar el número 30:

Arreglo: 10, 20, 30, 40, 50, 60, 70

1. Se selecciona el elemento central: 40.

2. Como 30 es menor que 40, se descarta la mitad derecha.

3. Se analiza la mitad izquierda y se encuentra el número 30.

Resultado: Elemento encontrado en la posición 2.

Características

  • Necesita que los datos estén ordenados.
  • Divide el espacio de búsqueda en dos partes.
  • Reduce considerablemente el número de comparaciones.
  • Es recomendable para estructuras con muchos elementos.

Ventajas

  • Es más rápida que la búsqueda secuencial en colecciones grandes y ordenadas.
  • Realiza pocas comparaciones.
  • Su funcionamiento es eficiente.

Desventajas

  • Los datos deben estar ordenados previamente.
  • Su implementación requiere controlar los límites del arreglo.
  • No es adecuada para recorrer directamente listas enlazadas.

Complejidad

Mejor caso: O(1)

Caso promedio: O(log n)

Peor caso: O(log n)

Espacial: O(1) en su versión iterativa.

Pseudocódigo

FUNCIÓN busquedaBinaria(arreglo, dato) inicio = 0 fin = longitud(arreglo) - 1 MIENTRAS inicio <= fin medio = (inicio + fin) / 2 SI arreglo[medio] == dato RETORNAR medio SI dato < arreglo[medio] fin = medio - 1 SINO inicio = medio + 1 FIN SI FIN MIENTRAS RETORNAR -1 FIN FUNCIÓN
Tema 6.3

Búsqueda por Funciones de Hash

La búsqueda por funciones de Hash es un método que permite localizar información mediante una función matemática que transforma una clave en una dirección o posición dentro de una tabla Hash.

Su principal objetivo es acceder directamente a la ubicación donde se encuentra almacenado un dato, evitando tener que revisar todos los elementos de la estructura.

¿Cómo funciona?

  • Se recibe el dato o clave que se desea buscar.
  • Se aplica una función Hash a la clave.
  • La función calcula una posición dentro de la tabla.
  • Se consulta la posición obtenida.
  • Si existe una colisión, se utiliza un método para resolverla.

Ejemplo práctico

Supongamos que tenemos una tabla con 100 posiciones y queremos almacenar el número 7259.

Función: h(clave) = clave % 100

Operación: 7259 % 100 = 59

El número 7259 se almacena en la posición 59 de la tabla. Para buscarlo nuevamente, se aplica la misma función y se consulta esa posición.

Tipos de funciones Hash

1. Función módulo

Consiste en dividir la clave entre el tamaño de la tabla y utilizar el residuo como dirección.

Ejemplo:

7259 % 100 = 59

2. Función cuadrática

Consiste en elevar la clave al cuadrado y seleccionar los dígitos centrales del resultado para obtener la posición correspondiente.

3. Función de plegamiento

Divide la clave en varias partes, suma los grupos obtenidos y utiliza los últimos dígitos del resultado como dirección.

Ejemplo:

7259 → 72 + 59 = 131

Dirección obtenida: 31

4. Función de truncamiento

Selecciona determinados dígitos de la clave para formar la dirección dentro de la tabla.

¿Qué son las colisiones?

Una colisión ocurre cuando dos claves diferentes generan la misma posición dentro de una tabla Hash. Para resolver este problema existen diferentes métodos.

Prueba lineal

Consiste en buscar la siguiente posición disponible cuando la dirección calculada ya está ocupada. Se revisan las posiciones consecutivas hasta encontrar un espacio libre.

Ventajas

  • Permite realizar búsquedas muy rápidas en promedio.
  • No necesita que los datos estén ordenados.
  • Permite acceder directamente a las posiciones calculadas.
  • Es útil para almacenar y consultar grandes cantidades de información.

Desventajas

  • Pueden producirse colisiones.
  • Necesita una función Hash adecuada.
  • Requiere memoria adicional para mantener la tabla.
  • Su rendimiento puede disminuir si existen demasiadas colisiones.

Complejidad

Mejor caso: O(1)

Caso promedio: O(1)

Peor caso: O(n)

Espacial: O(n)

Conclusión

Los métodos de búsqueda son fundamentales en la programación porque permiten localizar información dentro de diferentes estructuras de datos. La búsqueda secuencial destaca por su sencillez y porque no necesita datos ordenados. La búsqueda binaria permite encontrar elementos de manera más rápida cuando los datos están ordenados. Por otro lado, la búsqueda por funciones de Hash permite acceder directamente a las posiciones calculadas mediante una clave.

Conocer las características de cada método permite seleccionar el algoritmo más adecuado dependiendo de la cantidad de datos y las necesidades del programa.
